# Simple Code Editor

A lightweight, browser-based code playground for JavaScript, TypeScript, and HTML.

## Features

- **Multi-language support**: JavaScript, TypeScript, and HTML
- **Live preview**: See your code output in real-time
- **Console output**: Built-in console for debugging
- **Monaco Editor**: Powered by VS Code's editor
- **Resizable panels**: Customize your workspace layout
- **Dark/Light theme**: Choose your preferred theme
- **Auto-save**: Your code is saved to localStorage
- **Download code**: Export your work as files

## Usage

Simply open `index.html` in your browser or visit the [live demo](https://yourusername.github.io/SimpleCodeEditor/).

- Write code in the editor
- Click **Run** to execute (or it auto-runs on changes)
- Switch languages using the dropdown
- Use **Download** to save your code
- Drag the dividers to resize panels

## GitHub Pages Deployment

1. Push this repository to GitHub
2. Go to Settings → Pages
3. Select source: `main` branch, `/` (root)
4. Save and visit the provided URL
